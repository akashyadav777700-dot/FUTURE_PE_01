# Task 1: AI Website Copy Generator for Local Businesses 🚀

**Internship Track:** Prompt Engineering  
**Organization:** Future Interns  
**Task Code:** FUTURE_PE_01  



## 📌 Project Overview
This repository contains a structured prompt engineering system designed to generate conversion-focused, modern website copy for local businesses. For this task, I selected a local salon as my target client to address their customer acquisition and booking workflow needs.



## 🏬 Selected Business Profile
* **Business Name:** Hair & Care Salon
* **Business Type:** Local Unisex Salon & Beauty Parlour
* **Target Audience:** Young adults and teenagers (Ages 10–25)
* **Goal:** Generate clear, engaging website copy with a friendly tone, bulleted service menu, emojis, and direct contact CTAs.



## ⚙️ Prompt Engineering Logic & Framework
To ensure high-quality output from the AI model, the prompt was structured using the following core framework:
1. **Role Definition:** Assigned the AI as an expert web copywriter specializing in conversion optimization.
2. **Context & Target Persona:** Defined the audience age group (10-25) to control tone and vocabulary.
3. **Structured Deliverables:** Broken down into Homepage, Services Menu, and CTA sections.
4. **Formatting Constraints:** Mandated bullet points, promotional discounts, contact placeholders, and visual style notes (purple/white gradient theme).



## 🛠️ Tools Used
* **AI Model:** Google Gemini / ChatGPT
* **Documentation & Version Control:** GitHub



# 📋 Prompt Used

```text
Role: You are a professional website copywriter with conversion-focused web content.

Context: Create high-converting website content for a salon named "Hair & Care" located in Delhi.

Task:
1) Homepage: Create a Homepage copy with a strong and attractive headline, sub-headline, short intro, and key customer benefits.
2) Services Page: Create a Services section detailing the service menu in bullet points. Include benefits for each service and mention current active discounts.
3) CTA Section: Create a strong Call-to-Action section including contact details, map location, and direct booking options.
• Mobile Number: XXXXXXXX15

Formatting & Tone:
• Friendly, modern, and engaging tone specifically for young people (ages 10 to 25).
• Use clear headings, bullet points, and relevant emojis to make the content more interesting.
• Include a short summary section titled "Why Choose Hair & Care?".
• Suggest a aesthetic color theme (e.g., White & Purple gradient).
